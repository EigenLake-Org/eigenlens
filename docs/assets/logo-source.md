# Logo source

EigenLens uses the original EigenLake brand mark from [eigenlake.dev](https://www.eigenlake.dev/): three connected white nodes inside a black square.

- Source asset: [official SVG](https://www.eigenlake.dev/favicon/favicon.svg?v=2).
- Retrieved: 2026-10-24.
- `eigenlake-mark.svg` preserves the downloaded SVG without changes.
- `eigenlake-mark.png` is a 512 × 512 PNG export of that SVG, preserving its colors and geometry.

The README places the original brand mark beside the EigenLens product name.
